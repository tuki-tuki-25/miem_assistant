# MIEM Freshman Assistant — ИВТ НИУ ВШЭ

Прототип помощника первокурсника по содержанию дисциплин программы «Информатика и вычислительная техника» (учебный год 2026/2027).

## Что делает

1. Загружает каталог учебных курсов НИУ ВШЭ.
2. Открывает страницы конкретных дисциплин и оставляет только курсы, где явно указано `1-й курс`.
3. Извлекает аннотацию, цели, результаты обучения, содержание, элементы контроля, промежуточную аттестацию, литературу и метаданные.
4. Индексирует фрагменты по TF-IDF.
5. По вопросу пользователя выбирает релевантные фрагменты и передаёт их LLM для краткого ответа.
6. В ответе показывает источники — URL страниц НИУ ВШЭ.
7. Если релевантных материалов мало, ассистент не должен придумывать факт, а сообщает, что в доступных программах ответа нет.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python ingest.py
export OPENAI_API_KEY="..."     # Windows PowerShell: $env:OPENAI_API_KEY="..."
streamlit run app.py
```

Без `OPENAI_API_KEY` приложение запускается в режиме extractive retrieval: показывает найденные фрагменты и источники, без генерации ответа.

## Структура

- `app.py` — Streamlit UI и RAG-логика.
- `ingest.py` — загрузка и парсинг HSE.
- `requirements.txt` — зависимости.
- `data/courses.json` — локальный индекс после `python ingest.py`.
- `tests/test_questions.xlsx` — 30 тестовых вопросов: 20 позитивных и 10 негативных.
- `presentation.pptx` — краткая презентация решения.

## Важное ограничение

Каталог НИУ ВШЭ является внешним источником и может обновляться. Для воспроизводимости в проекте предусмотрен локальный `data/courses.json`; перед демонстрацией можно повторно запустить `python ingest.py` и получить актуальный срез.
